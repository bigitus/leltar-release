# Leltár – kiadások

A Leltár vonalkódolvasós leltározó program telepítői és frissítési manifestje.
A program használatához licenckulcs kell.

- Telepítő és hordozható változat: [Releases](https://github.com/bigitus/leltar-release/releases)
- `update.manifest`: a program ebből tudja meg, van-e újabb változat (az aláírása: `update.manifest.sig`)
